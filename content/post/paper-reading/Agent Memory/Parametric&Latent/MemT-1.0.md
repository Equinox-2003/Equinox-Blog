## 零、写在前面

**MemTensor** 昨天发布了技术报告并且开源了模型权重，今天就宣发满天飞了。因为前几周一直在看记忆原生的工作，也跑了一些包括 **Metis** 在内的开源方案，做了各种验证后，个人其实并不看好现在走的路线（记忆原生的想法是很好的，但是现在的范式还是 **Fast Weight Update**）。

这次的 **MemT-1.0** 的规模就远超之前的 Metis 了，以 **Qwen3.6-35B-A3B** 和 **DeepSeek-V4-Flash** 分别为 backbone 发了两个模型，分别是 **MemT-1.0-Nano** 和 **MemT-1.0-Flash**。

模型做的更大，训练投入资源更多，并且这次还在一些 Agent Harness 的 bench 上做了测试，以说明记忆是 RSI 不可缺少的一环。

之前 Metis 在记忆的一些bench的表现惨不忍睹，这次差不多可以跟 mem0 打平了，不过这次是 LLM as Judge，是否有水分也难说。

宣发的推文里面有一个 MemT-1.0 测试迷宫游戏的视频，和一个普通的模型第一次表现接近，但是第二次，因为 MemT-1.0 的原生记忆发力，直接走了最优路线，但是普通模型仍和第一次一样试错前进。

那么这些看起来还不错的提升背后做了哪些改进呢？——**Scale**。

这个还挺巧的，上周做了一些实验，想法就是想要做推理时 native memory Scale。分别测了 δMem 和 Metis，按照我的想法，随着写入次数的增加，初始肯定会有涨点，但是因为写入增加，噪声也增加，那么又会降点，所以应该会得到一条倒U型曲线。

最后的结果是，δMem 确实得到了这样一条曲线，但是因为 δMem 的规模太小了，所以升点不明显，但是 Metis 就比较诡异了，持续掉点。

当时我的结论是，δMem 我是 token level 的信息注入，写入就是类似 deltanet 的方法，但是 Metis 就比较微妙了，内部是有预训练的门控，然后 top-p token 写入。所以问题在哪我很难定位，所以最后也是不打算再往这个路线深挖了，毕竟做的人不多，大家也不好 follow。

但是今天的 MemT-1.0 的架构看了下基本和 Metis 一模一样，唯一不同的应该就是**把 top-p 的 token 写入去掉**了，然后仿 MoE 加入了 **Mixture of Storage（MoS）**，但是不像 MoE 还要做路由，他直接是所有专家一起工作的。

总得来说，架构确实有更新，但基本就是比较粗糙的力大砖飞，然后训练阶段也做了一些调整。

虽然这次宣发的实验结果看起来比较好看，但技术个人感觉没有什么创新，论文花了一些篇幅去讲 GDN-2 的缺陷，然后提出了 SGDN-2，但是后面关于 GDN-2 的消融，SGDN-2 相比 GDN-2 的升点并不明显，这个就比较耐人寻味了。

总的来说，原生记忆个人觉得如果能做好，那么在很多场景都是大有可为的，但是现在还是炒作包装的有点过了……

不出意外的话 MemT 后续版本就是做一下 MoS 的语义路由，然后做一些 infra 的优化，至于**如何解决写入污染、早期记忆衰退、固定容量 Memory 如何外推**，感觉也不是短时间可以攻破的……除非只关注端侧模型，那么这套范式或许还是可行的。





## 一、Metis => MemT-1.0

推理（Reasoning）与多模态（Multimodality）能力已逐步从外部辅助系统内化为底座模型的原生能力，现在主流观点认为**“记忆（Memory）”**是实现自进化、持续学习的核心模块。

传统的外部记忆方案（full context、RAG）受限于随序列长度线性甚至二次方增长的计算与显存开销，且存储与检索过程游离于模型端到端计算之外。

**Mem**Tensor 团队在此前发布的初代记忆基座模型 **Metis** 中，首次提出了将记忆内化为模型前向计算一部分的“原生记忆（Native Memory）”范式，通过分离**在线**动态更新的**局部记忆块（Local Memory Block）**与**离线**训练的**超记忆块（Hyper Memory Block）**，实现了推理阶段无需梯度更新（Gradient-free）的在线记忆演进。

然而，初代 Metis 原型在架构表达力、更新粒度以及训练规模上存在显著瓶颈。Metis 依赖离散token选择机制（Token Selection，如基于 $\alpha$ top-$p$ 的筛选）从每个交互回合中挑取部分隐状态写入记忆，采用标准的门控增量网络（Gated DeltaNet, GDN）更新规则，且仅在约 4.06 亿（406M）合成token和最高 27B 稠密底座（Qwen3.5）上进行了验证。

最新发布的 **MemT-1.0** 在延续“局部动态记忆 + 可训练超记忆”双模块骨架的基础上，对底层算子、容量扩展机制、基座准备及训练数据规模进行了全方位重构，从而在 11 项权威记忆基准测试中实现了跨越式的性能提升。

MemT-1.0 能够碾压 Metis 基本可以归因于：

1.  模型放弃了有损的token筛选与回合级池化，转向逐token（Token-level）连续状态演进，使得模型能够在同一交互回合内实时处理信息衰减并修正早期建立的关联。
2.  团队从数学底层修复了 Gated DeltaNet-2 (GDN-2) 的非对称能量放大缺陷，使记忆半衰期突破了原先仅约 5 个token的理论稳定上限，扩展至最高 32,768 个token的初始化跨度。
3.  研究构建了高达 34B token的“继续预训练（CPT）+ 离线策略全上下文知识蒸馏（Off-policy KD）”两阶段管线，训练数据量级较 Metis 暴增逾 80 倍。
4.  架构引入了混合存储（Mixture-of-Storage, MoS）与多通道状态张量，将单轨迹在线记忆容量扩展至千万乃至数亿级浮点元素。

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1792499237831_image.png)

### 2.1 并行记忆注意力与双核心块解耦

MemT-1.0 将多步交互建模为离散时间步序列 $t \in \{1, 2, \dots, T\}$。在每一步 $t$ 中，输入序列定义为 $S_{t,k} = X_t \parallel Y_{t,<k}$，其中 $X_t$ 为当前用户输入，$Y_{t,<k}$ 为已生成的回复前缀，序列长度为 $L_{t,k}$。

为了在不破坏预训练基座原有能力的前提下注入记忆，MemT-1.0 保持基座原有的前置归一化（Pre-Attention）、原始自注意力（Original Attention）及后置处理（Post-Attention/FFN）完全冻结不变，仅在选定的 Transformer 层中挂载一个并行的 **原生记忆块（Native Memory Block）**：

$$\tilde{H}_{t,k}^{(l)} = \text{Pre-Attention}(H_{t,k}^{(l-1)}), \quad A_{\text{ori},t,k}^{(l)} = \text{Attention}(\tilde{H}_{t,k}^{(l)})$$

$$A_{\text{mem},t,k}^{(l)} = \text{MemoryAttention}(\tilde{H}_{t,k}^{(l)}; M_t^{(l)}), \quad A_{t,k}^{(l)} = A_{\text{ori},t,k}^{(l)} + A_{\text{mem},t,k}^{(l)}$$

$$H_{t,k}^{(l)} = \text{Post-Attention}(A_{t,k}^{(l)})$$

在这一并行融合架构中，每一层的原生记忆块由两个角色截然不同的子模块构成。

第一个子模块是 **局部记忆块（Local Memory Block）**，负责在推理阶段动态存储特定会话轨迹的在线信息。

在第 $t$ 步、第 $l$ 层，其状态表示为一个三维张量 $M_t^{(l)} \in \mathbb{R}^{H_{kv} \times d_k \times d_v}$，其中 $H_{kv}$ 为记忆通道数（对齐查询头数 $H_q$），$d_k$ 与 $d_v$ 分别为记忆键（Key）和值（Value）的特征维度。相较于 Metis，MemT-1.0 彻底移除了冗余的查询-键归一化向量，并在新轨迹开始时统一初始化为全零张量 $M_1^{(l)} = 0$。

第二个子模块是 **超记忆块（Hyper Memory Block）**，包含所有控制记忆读写与门控的静态可训练参数 $\phi$，在训练阶段通过梯度下降优化，而在在线交互阶段保持完全固定。其参数涵盖记忆查询、键、值投影矩阵（$\tilde{W}_Q^{(l)}, \tilde{W}_K^{(l)}, \tilde{W}_V^{(l)}$）、擦除门投影 $W_\beta^{(l)}$、写入门投影 $W_\omega^{(l)}$、遗忘门低秩分解组件（$W_f^{(l)}, W_\lambda^{(l)}, b_\lambda^{(l)}, s^{(l)}$）以及读取输出门的共享降维投影 $W_{g/d}^{(l)}$ 与多通道升维投影 $W_{g/u}^{(l)}$。通过将在线演进状态 $M_t^{(l)}$ 与静态读写规则 $\phi$ 彻底解耦，模型在推理期间只需执行前向矩阵运算即可完成状态更新与历史读取，完全无需在线反向传播。

### 2.2 标准 GDN-2 vs 对称稳定化机制（SGDN-2）

MemT-1.0 在架构层面的最大理论贡献之一，是在附录 C 中严格证明了线性注意力变体 **Gated DeltaNet-2 (GDN-2)** 在递归更新中存在固有的数值不稳定性，并提出了 **对称化修正（Symmetrization Fix，即 SGDN-2）**。

在标准 GDN-2 中，为了比一代 GDN 更灵活地控制记忆，擦除门（Erase Gate, $b_t \in (0,1)^{d_k}$）与写入门（Write Gate, $w_t \in (0,1)^{d_v}$）被解耦，且门控直接作用于特征通道而非标量。忽略层与多头索引，设第 $t$ 个token经过 L2 归一化后的键向量为 $k_t \in \mathbb{R}^{1 \times d_k}$（满足 $\Vert{}k_t\Vert{}_2 = 1$），值向量为 $v_t \in \mathbb{R}^{1 \times d_v}$，对角衰减矩阵为 $D_t = \text{Diag}(d_t)$，标准 GDN-2 的单步递归更新方程为：

$$S_t = \underbrace{\left(I - k_t^\top (b_t \odot k_t)\right)}_{A_t} D_t S_{t-1} + \underbrace{k_t^\top (w_t \odot v_t)}_{B_t}$$

研究团队通过子空间正交分解揭示了该更新公式在长序列中发散崩溃的几何机理。定义擦除向量 $a = b \odot k$，其在 $k$ 方向上的投影标量为 $\rho = k a^\top = \sum_i b_i k_i^2 \in (0,1)$，模长平方为 $m = \Vert{}a\Vert{}_2^2 = \sum_i b_i^2 k_i^2 \in [\rho^2, \rho)$。由于门控向量 $b$ 的各个通道分量通常不相等（即 $b$ 不是常数向量），向量 $a = b \odot k$ 与原向量 $k$ **不再共线**。

将 $a$ 分解为平行于 $k$ 的分量和垂直于 $k$ 的单位正交向量 $e$（满足 $e k^\top = 0, \Vert{}e\Vert{}_2 = 1$），即 $a = \rho k + \gamma e$，其中正交偏离度 $\gamma^2 = m - \rho^2 \ge 0$。在正交基 $\{k, e\}$ 下，擦除转移矩阵 $A = I - k^\top a$ 的非平凡 $2 \times 2$ 子块表现为上三角非对称矩阵：

$$A_2 = \begin{bmatrix} 1 - \rho & -\gamma \\ 0 & 1 \end{bmatrix}$$

当记忆状态中包含沿正交方向 $e$ 的分量时，执行擦除操作会得到 $e A^\top = e - \gamma k$，其欧几里得范数平方变为 $\Vert{}e A^\top\Vert{}_2^2 = 1 + \gamma^2 > 1$（只要 $\gamma \neq 0$）。这意味着标准 GDN-2 在按 $a = b \odot k$ 计算擦除幅度、却沿 $k$ 方向执行减法修正时，会把正交子空间 $e$ 的能量无端投射并放大到 $k$ 方向上。

通过计算 $A_2^\top A_2$ 的最大特征值，可推导出转移矩阵 $A$ 的谱范数（最大奇异值）在 $\rho = 1/3$ 时达到峰值上界 $1 \le \Vert{}A\Vert{}_2 < \frac{2}{\sqrt{3}} \approx 1.1547$。为了保证整体递归转移矩阵 $P_t = A_t D_t$ 满足一致收缩条件 $\Vert{}P_t\Vert{}_2 \le \frac{2}{\sqrt{3}} \bar{d} < 1$ 以避免状态爆炸，对角遗忘门的最大衰减系数必须满足 $\bar{d} < \frac{\sqrt{3}}{2} \approx 0.866$。代入半衰期公式可得：

$$t_{1/2} = \frac{\ln 2}{-\ln \bar{d}} = \frac{\ln 2}{-\ln(\sqrt{3}/2)} \approx 4.82 \text{ tokens}$$

这一数学推论极其深刻：在标准 GDN-2 下，若要从理论上绝对保证递归状态不发散，遗忘门的记忆半衰期最多只能维持约 5 个token，这与长程记忆模型的初衷完全背道而驰。

针对这一病态特性，MemT-1.0 提出了对称化解决方案（SGDN-2）。由于不稳定性根植于 $A = I - k^\top k \text{Diag}(b)$ 破坏了矩阵对称性，MemT-1.0 将对角门控矩阵 $\text{Diag}(b)$ 开方后均匀分配至左右两侧的键向量，定义修正后的调制键向量 $U_{t,i}^{(l)} = \sqrt{\beta_{t,i}^{(l)}} \odot K_{t,i}^{(l)}$，从而将擦除矩阵重构为对称形式：

$$A = I - \text{Diag}(\sqrt{\beta}) k^\top k \text{Diag}(\sqrt{\beta}) = I - (\sqrt{\beta} \odot k)^\top (\sqrt{\beta} \odot k) = I - U^\top U$$

在 **SGDN-2** 下，读取方向与擦除方向均严格对齐于同一向量 $U$，正交偏差 $\gamma \equiv 0$。从几何视角审视，擦除算子仅将平行于 $U$ 的状态分量按比例 $1 - \Vert{}U\Vert{}_2^2 \in (0,1)$ 收缩，而使正交补空间保持完全不变，算子谱范数恒满足 $\Vert{}A\Vert{}_2 \le 1$（非扩张映射）。借此，遗忘门不再需要承担“压制算子发散”的额外负担，MemT-1.0 得以将各通道遗忘门半衰期 $\tau_{1/2}$ 按对数均匀分布初始化在 $[2048, 32768]$（Nano）和 $[128, 32768]$（Flash）token区间内，真正实现了长跨度记忆留存。

### 2.3 混合存储（Mixture-of-Storage, MoS）容量扩展机制

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1792501011495_image.png)

为了在不修改基座参数的前提下同时放大在线记忆状态容量与超记忆可训练参数，MemT-1.0 提出了 **混合存储（MoS）** 架构，将单个原生记忆块水平扩展为 $E$ 个并行的记忆专家（Memory Experts），状态张量扩展为 $\mathcal{M}_{t,\text{MoS}}^{(l)} = \{M_{t,e}^{(l)}\}_{e=1}^E \in \mathbb{R}^{E \times H_{kv} \times d_k \times d_v}$。

与常规稀疏激活的混合专家模型（Sparse MoE，每次仅激活 Top-$k$ 个专家以节省算力）不同，**MoS 采用面向全专家的稠密路由（Dense Routing）机制**，每一个记忆专家都参与每次读写计算，路由概率直接决定信息在不同专家状态槽中的写入权重与读取融合比例。其核心机制建立在 **共享地址双路由（Shared-Address Routing）** 之上：所有专家共享一个可学习的语义专家地址矩阵 $C^{(l)} = [c_1^{(l)}, c_2^{(l)}, \dots, c_E^{(l)}]^\top \in \mathbb{R}^{E \times d_{\text{addr}}}$，而存储过程与利用过程分别拥有独立的路由投影矩阵 $W_{\text{route/s}}^{(l)}, W_{\text{route/u}}^{(l)} \in \mathbb{R}^{d \times d_{\text{addr}}}$，从而共享相同的专家语义寻址空间但学习不同的读写投影：

$$\alpha_{s,t}^{(l)} = \text{Softmax}\left(\tilde{H}_t^{(l)} W_{\text{route/s}}^{(l)} C^{(l)\top}\right) \in \mathbb{R}^{L_t \times E}, \quad \alpha_{u,t}^{(l)} = \text{Softmax}\left(\tilde{H}_t^{(l)} W_{\text{route/u}}^{(l)} C^{(l)\top}\right) \in \mathbb{R}^{L_t \times E}$$

在写入调制阶段，第 $e$ 个专家的存储路由概率 $\alpha_{s,t,e}^{(l)}$ 直接作为标量乘法器缩放该专家的擦除门与写入门，即 $\tilde{\beta}_{t,e}^{(l)} = \alpha_{s,t,e}^{(l)} \odot \beta_{t,e}^{(l)}$ 以及 $\tilde{\omega}_{t,e}^{(l)} = \alpha_{s,t,e}^{(l)} \odot \omega_{t,e}^{(l)}$（对数衰减率保持不变 $\tilde{\lambda}_{t,e}^{(l)} = \lambda_{t,e}^{(l)}$），随后执行各自的 SGDN-2 状态更新。当某个专家对当前token的路由权重 $\alpha_{s,t,e}^{(l)} \to 0$ 时，其擦除与写入门同步趋近于零，从而保护该专家已存储的历史记忆不被当前无关token冲刷。在读取融合阶段，各专家独立完成矩阵读取与输出门控后，按利用路由概率加权求和得到最终记忆注意力输出 $A_{\text{mem},t,i}^{(l)} = \sum_{e=1}^E \alpha_{u,t,i,e}^{(l)} A_{\text{mem},t,i,e}^{(l)}$。

### 2.4 数据前向过程示例

为了彻底厘清 MemT-1.0 在实际运行中的计算逻辑，以下结合 **MemT-1.0-Nano** 的真实超参数配置（见附录 B 表 6：基座隐藏层维度 $d=2048$，挂载于 10 个全注意力层，通道数 $H_q = H_{kv} = 16$，键值维度 $d_k = d_v = 256$，单专家 $E=1$，遗忘/输出门秩 $d_{\text{gate}} = d_{g/d} = 256$），完整推演一个交互步 $t$ 内的张量前向流动过程，并给出一个二维精确数值算例。

#### 2.4.1 张量维度级前向过程推演（以 MemT-1.0-Nano 单层为例）

假设当前处于第 $t$ 轮对话，模型已经历了前 $t-1$ 轮交互，当前层内存中驻留着上一轮结束时固化的 FP32 动态记忆状态快照 $M_t^{(l)} \in \mathbb{R}^{16 \times 256 \times 256}$（共 $1,048,576$ 个浮点数，占 $4\text{ MiB}$；10 层合计 $40\text{ MiB}$）。

##### 第一阶段：在线记忆利用过程（Memory Utilization Procedure，解码生成期间实时触发）

在用户输入当前问题 $X_t$ 并逐token自回归生成回复 $Y_t$ 时，假设当前步处理的token序列长度为 $L$（在预填充阶段 $L$ 为输入长度，在解码阶段单步 $L=1$），前置归一化后的输入隐状态为 $\tilde{H}_t^{(l)} \in \mathbb{R}^{L \times 2048}$（BF16 精度）。在整个第 $t$ 步生成过程中，$M_t^{(l)}$ 作为只读快照保持恒定不变。

| **步骤序号** | **算子操作名称**         | **数学表达式**                                               | **输入张量维度**                                             | **参数张量维度**                                             | **输出张量维度**                    | **关键设计目的与数值细节**                                   |
| ------------ | ------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ----------------------------------- | ------------------------------------------------------------ |
| **Read-1**   | **查询投影与 L2 归一化** | $Q_{t,h}^{(l)} = \text{L2Norm}(\tilde{H}_t^{(l)} \tilde{W}_{Q,h}^{(l)})$ | $\tilde{H}_t^{(l)}: [L, 2048]$                               | $\tilde{W}_Q^{(l)}: [16, 2048, 256]$                         | $Q_t^{(l)}: [16, L, 256]$           | 初始化复制自基座查询投影；沿特征维 $d_k=256$ 执行 L2 归一化以稳定内积范围。 |
| **Read-2**   | **状态矩阵关联读取**     | $R_{t,h}^{(l)} = \frac{Q_{t,h}^{(l)} M_{t,h}^{(l)}}{\sqrt{d_k}}$ | $Q_{t,h}^{(l)}: [L, 256]$ $M_{t,h}^{(l)}: [256, 256]$        | 无静态权重 (纯状态矩阵乘法)                                  | $R_t^{(l)}: [16, L, 256]$           | 将查询与 $256 \times 256$ 键值记忆槽做矩阵相乘并除以 $\sqrt{256}=16$，耗时与历史总长无关。 |

| **Read-4**   | **软截断激活与拼接**     | $\text{Concat}_{h=1}^{16}[\text{RMSNorm}(R_{t,h}^{(l)}) \odot \text{SoftCapSiLU}(G_{t,h}^{(l)})]$ | $R_t^{(l)}: [16, L, 256]$ $G_t^{(l)}: [16, L, 256]$          | RMSNorm 增益: $[16, 256]$                                    | $A_{\text{mem},t}^{(l)}: [L, 4096]$ | $\text{SoftCapSiLU}(x) = 2 \tanh(\text{SiLU}(x)/2)$ 将门控幅值软截断在 $(-2, 2)$ 内以防训练早期梯度爆炸。 |
| **Read-5**   | **并行分支残差合流**     | $A_{\text{out}} = (A_{\text{ori},t}^{(l)} + A_{\text{mem},t}^{(l)}) W_{\text{out}}^{(l)}$ | $A_{\text{ori},t}^{(l)}: [L, 4096]$ $A_{\text{mem},t}^{(l)}: [L, 4096]$ | 基座冻结 $W_{\text{out}}^{(l)}: [4096, 2048]$                | $H_{\text{attn}}^{(l)}: [L, 2048]$  | 16 个头拼接成的 4096 维记忆读取向量直接加到基座门控后注意力输出上，共享基座输出投影。 |



##### 第二阶段：原生记忆存储过程（Memory Storage Procedure，回合结束或满 2048 token步长时触发）

当第 $t$ 轮完整交互序列 $S_t = X_t \parallel Y_t$（假设长度为 $L_t$）生成完毕后，系统触发存储过程，利用该回合的前置归一化隐状态 $\tilde{H}_t^{(l)} \in \mathbb{R}^{L_t \times 2048}$ 将新信息写入记忆槽，使状态从 $M_t^{(l)}$ 演进为 $M_{t+1}^{(l)}$。

存储过程首先执行多通道键值投影，将 $\tilde{H}_t^{(l)}$ 分别通过 $\tilde{W}_K^{(l)} \in \mathbb{R}^{16 \times 2048 \times 256}$ 和 $\tilde{W}_V^{(l)} \in \mathbb{R}^{16 \times 2048 \times 256}$（初始化复制自基座的 2 个 GQA KV 头，每个复制 8 份成为 16 个独立可训练记忆头），并对键执行 L2 归一化，得到 $K_t^{(l)} \in \mathbb{R}^{L_t \times 16 \times 256}$ 和 $V_t^{(l)} \in \mathbb{R}^{L_t \times 16 \times 256}$。随后，模型并行计算三路门控信号：擦除门与写入门通过稠密投影并经 Sigmoid 激活得到 $\beta_t^{(l)} = \sigma(\tilde{H}_t^{(l)} W_\beta^{(l)}) \in (0,1)^{L_t \times 16 \times 256}$ 和 $\omega_t^{(l)} = \sigma(\tilde{H}_t^{(l)} W_\omega^{(l)}) \in (0,1)^{L_t \times 16 \times 256}$；对数遗忘门先经低秩矩阵 $W_f^{(l)} \in \mathbb{R}^{2048 \times 256}$ 降维得到 $F_t^{(l)} \in \mathbb{R}^{L_t \times 256}$，再计算负值对数衰减率 $\lambda_{t,h}^{(l)} = -\exp(s_h^{(l)}) \odot \text{Softplus}(F_t^{(l)} W_{\lambda,h}^{(l)} + b_{\lambda,h}^{(l)}) \in (-\infty, 0)^{L_t \times 256}$，对应的单步乘法衰减对角阵为 $D_{t,i,h}^{(l)} = \text{Diag}(\exp(\lambda_{t,i,h}^{(l)})) \in (0,1)^{256 \times 256}$。

完成投影与门控计算后，算子进入 SGDN-2 逐token递归状态演进：首先计算对称调制键向量 $U_{t,i,h}^{(l)} = \sqrt{\beta_{t,i,h}^{(l)}} \odot K_{t,i,h}^{(l)} \in \mathbb{R}^{1 \times 256}$ 以及调制值向量 $Z_{t,i,h}^{(l)} = \omega_{t,i,h}^{(l)} \odot V_{t,i,h}^{(l)} \in \mathbb{R}^{1 \times 256}$。随后从初始状态 $\tilde{M}_{t,0,h}^{(l)} = M_{t,h}^{(l)}$ 出发，按token索引 $i = 1, 2, \dots, L_t$ 依次执行秩-1（Rank-1）更新（实际硬件执行时采用 64 token分块 WY 并行算子）：

$$\tilde{M}_{t,i,h}^{(l)} = \underbrace{D_{t,i,h}^{(l)} \tilde{M}_{t,i-1,h}^{(l)}}_{\text{历史记忆指数衰减}} - \underbrace{U_{t,i,h}^{(l)\top} \left( U_{t,i,h}^{(l)} D_{t,i,h}^{(l)} \tilde{M}_{t,i-1,h}^{(l)} \right)}_{\text{沿调制键方向精准擦除旧关联}} + \underbrace{U_{t,i,h}^{(l)\top} Z_{t,i,h}^{(l)}}_{\text{外积写入新键值关联}}$$

当第 $L_t$ 个token处理完毕后，最终状态 $\tilde{M}_{t,L_t,h}^{(l)}$ 即被提交固化为下一轮交互的输入记忆状态 $M_{t+1,h}^{(l)}$，而当前轮的原始文本序列 $S_t$ 及其注意力 KV Cache 即可直接释放，不再携带至下一轮。

#### 2.4.2 数值级算例对比：GDN-2 与 SGDN-2 的单步擦除演算

为了直观展现上述公式中“开根号对称化（$U = \sqrt{\beta} \odot K$）”阻止状态爆炸的具体过程，以下提取报告附录 C 图 12 的二维精确数值配置进行对比推演。假设键维度 $d_k = 2$，当前仅考察纯擦除步（令衰减矩阵 $D = I_2$，新写入项 $Z = 0$）。设输入归一化键向量为 $k = \left[\frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}}\right] \approx [0.7071, 0.7071]$（满足 $\|k\|_2 = 1$），通道擦除门向量高度不均匀，取为 $b = [0.99, 0.01]$（即第 1 通道强烈擦除，第 2 通道几乎保留）。同时，假设上一时刻记忆状态中存储着一个与当前键 $k$ **完全正交（毫不相干）** 的历史状态向量 $y = e = \left[\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}}\right] \approx [0.7071, -0.7071]$（内积 $k \cdot y^\top = \frac{1}{2} - \frac{1}{2} = 0$，且初始能量范数 $\|y\|_2 = 1.000$）。理想情况下，既然当前键 $k$ 与历史状态 $y$ 完全正交，擦除操作不应当凭空放大 $y$ 的范数。

| **演算步骤与指标**                           | **方案 A：标准 GDN-2 更新（未对称化）**                      | **方案 B：MemT-1.0 SGDN-2 更新（对称化修正）**               |
| -------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **1. 调制向量构造**                          | $a = b \odot k = \left[\frac{0.99}{\sqrt{2}}, \frac{0.01}{\sqrt{2}}\right] \approx [0.7000, 0.0071]$ | $u = \sqrt{b} \odot k = \left[\frac{\sqrt{0.99}}{\sqrt{2}}, \frac{\sqrt{0.01}}{\sqrt{2}}\right] \approx [0.7036, 0.0707]$ |
| **2. 状态内积读取值**                        | $a \cdot y^\top = \frac{0.99 - 0.01}{2} = 0.4900$            | $u \cdot y^\top = \frac{0.9950 - 0.1000}{2} = 0.4475$        |
| **3. 单步擦除状态更新**                      | $y'_{\text{GDN2}} = y - (a \cdot y^\top) k \approx [0.3606, -1.0536]$ | $y'_{\text{SGDN2}} = y - (u \cdot y^\top) u \approx [0.3923, -0.7387]$ |
| **4. 更新后状态范数 ($\Vert{}y'\Vert{}_2$)** | $\sqrt{\frac{0.51^2 + (-1.49)^2}{2}} = \sqrt{1.2401} \approx \mathbf{1.1136 > 1.000}$ | $\sqrt{0.3923^2 + (-0.7387)^2} = \sqrt{0.6996} \approx \mathbf{0.8364 \le 1.000}$ |
| **5. 算子最大方向增益与稳定性**              | 最大增益 **1.139 > 1**（能量膨胀 11.36%，长序列易溢出）      | 最大增益 **1.000**（严格非扩张映射，彻底消除发散）           |



上表的对比清晰表明，在标准 GDN-2 下，仅仅经历一步纯擦除操作，原本正交的无关联状态能量就凭空膨胀了 **11.36%**，在数万token的连续乘积下极易引发数值溢出；而 SGDN-2 将读取方向与擦除方向统一锁定在调制向量 $u$ 上，使算子的最大方向增益严格受限于 $1.000$，从数学根源上消除了正交子空间交叉污染引发的发散风险。

## 三、Training & Infra

### 3.1 基座准备（Backbone Preparation）：厘清“行为可靠性”与“信息缺失”的边界

在挂载原生记忆模块之前，MemT-1.0 团队认为：**记忆基座模型从底层主干继承了两样东西——预训练固化的“知识（Knowledge）”以及将这些知识转化为正确输出的“行为可靠性（Reliability）”，而后训练对这两者的作用机制截然不同**。

研究团队对 DeepSeek-V4-Flash 的逐题归因实验证实，基于验证器过滤的自采样微调（Rejection Sampling / RL）本质上只是对基座已有的输出分布进行重新加权（Reweighting），收益高度集中在基座“偶尔能做对（Occasionally solved）”的任务上；对于基座在 8 次尝试中从未解出的任务，常规后训练后的准确率依然停留在 **1.6%–4.0%** 的极低水平。然而，在一组困难知识探针集上，一旦在上下文中直接提供相关事实，基座准确率便从 **27% 暴涨至 91%**。这证明基座后训练主要解决的是程序规范与执行可靠性，而真正缺失的新信息必须交由原生记忆模块在推理时动态供给。

基于这一认识，团队在冻结 DeepSeek-V4-Flash 之前，围绕通用能力、Agentic Coding 和 Agentic Working三条轨道，实施了三步式基座准备管线。

-   第一步是 **能力画像（Capability Profiling）**，对每个任务重复采样，将其划分为“稳定解出”、“偶发解出”与“无法解出”三类。
-   第二步是 **干预归因（Attribution by Intervention）**，对失败样本在上下文中注入疑似缺失的要素（评分规范、程序性提示或外部事实）并重跑；若注入规范或程序提示后成功，则归因于行为或流程缺失；若仅在注入事实时成功，则归因于知识缺失并交由后续原生记忆解决；若任何干预均失败，则直接从合成集中剔除。
-   第三步是 **条件化合成（Capability-Conditioned Synthesis）**，稳定解出任务用于回放锚定（Replay），偶发解出任务采用通过单元测试或沙盒验证的自采样轨迹，而缺失规范或流程的任务则采用引导式采样（提示仅出现在采样上下文而不在训练目标中）或更强模型的风格对齐示范。

经过 5 轮全混合迭代与逾 50 次训练实验，团队最终构建了包含 **12.65 万条轨迹（共 2.4B token，其中 1.1B 计入损失，智能体长轨迹占损失token的约 90%）** 的精选数据集。这使准备后的 DeepSeek-V4-Flash（284B 总参数 / 13B 激活参数）在 6 项核心基准上平均提升 **6.3 个百分点**，并在 SWE-bench Multilingual（83.46%）和 IFBench v2（81.67%）上超越了体量更大的 GLM-5.3 Flash（320B/18B）乃至旗舰级 DeepSeek-V4 Pro（1.6T 总参数 / 49B 激活参数），为后续记忆训练提供了强大的宿主与蒸馏教师。

### 3.2 34B 语料构建与“CPT + 离线策略蒸馏”两阶段训练

在基座冻结后，MemT-1.0 仅优化超记忆参数 $\phi$（以及 MoS 路由参数），训练语料总计 **340 亿（34B）token**，分为两个阶段推进：

| **训练阶段**                         | **语料规模与构成**                                           | **序列切分与记忆状态传递**                                   | **监督目标与损失函数**                                       | **核心训练目的**                                             |
| ------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **第一阶段：继续预训练 (CPT)**       | **20B token**：大规模长文本与连续序列通用语言建模语料。      | 将 64K 打包序列切分为连续不重叠的 **2,048 token片段 (Segment)**，每个片段作为一步 $t$；基座注意力仅限当前 2K 片段内，跨片段依赖完全通过状态 $M_t \to M_{t+1}$ 传递。 | **硬标签交叉熵损失 ($\mathcal{L}_{\text{CE}}$)**：$\lambda_{\text{CE}}=1, \lambda_{\text{KD}}=0$，对片段内所有真实下一token进行监督。 | 建立在受限局部窗口下依赖原生记忆状态进行长程语言建模的基础读写能力。 |
| **第二阶段：后训练 (Post-Training)** | **14B token**：统一为 `上下文-查询-回答` 格式，涵盖三大类：(1) 记忆原生语言建模；(2) 存储与利用任务（摘要、续写、压缩）；(3) 长程记忆问答任务（含 MemOS 脱敏真实交互模式）。 | 历史上下文 $C_{<t}$ 按时间顺序每 2K token执行一次原生存储更新生成 $M_t$；回答阶段学生模型仅接收当前查询 $X_t$、回复前缀 $Y_{t,<k}$ 及状态 $M_t$。 | **离线策略 Top-64 前向 KL 知识蒸馏 ($\mathcal{L}_{\text{KD}}$)**：$\lambda_{\text{KD}}=1, \lambda_{\text{CE}}=0$；仅对回复token计算损失，历史与查询token掩码 $m_{t,k}=0$。 | 迫使仅靠记忆状态 $M_t$ 的学生模型逼近拥有完整文本历史 $C_{<t}$ 的冻结基座教师的输出分布。 |



后训练阶段的 **离线策略知识蒸馏（Off-policy Knowledge Distillation）** 设计尤为精妙。冻结的基座模型（不带记忆模块）直接将完整历史文本 $C_{<t}$ 拼接到上下文中作为全知教师，输出下一token概率分布 $q_{t,k}(v) = P(v \mid C_{<t}, X_t, Y_{t,<k}; \theta_b)$；而 MemT-1.0 学生模型看不到 $C_{<t}$，只能依赖局部记忆状态生成分布 $p_{t,k}(v) = P(v \mid X_t, Y_{t,<k}; \theta_b, \phi, M_t)$。为了降低存储与通信开销，系统在每个监督位置仅截取教师概率最高的 **Top-64** token集合 $\mathcal{K}_{t,k}$ 进行重归一化得到 $\hat{q}_{t,k}(v)$（温度 $T_d = 1.0$），计算前向 KL 散度：

$$l_{t,k}^{\text{KL}} = T_d^2 \sum_{v \in \mathcal{K}_{t,k}} \hat{q}_{t,k}(v) \log \frac{\hat{q}_{t,k}(v)}{p_{t,k}^{T_d}(v)}$$

值得关注的是，教师分布是在 Top-64 子集上重归一化的，而学生分布 $p_{t,k}(v)$ 依然在完整词表 $\mathbb{V}$ 上归一化——这意味着该损失函数不仅迫使学生在 Top-64 候选词上对齐教师的精细概率分布，还会自动惩罚学生将概率质量分配给 Top-64 之外的无关词元。尽管历史上下文token不直接产生预测损失（$m_{t,k}=0$），但回答阶段的 KL 损失梯度会穿过矩阵读取算子，沿时间步反向传播至早期的 SGDN-2 写入门、擦除门与键值投影，从而端到端地教会超记忆网络在历史中应当挑选哪些信息留存。

### 3.3 System Infra：分块算子、窗口重计算与有状态推理

在工程实现上，原生记忆引入了两个棘手的系统级挑战：一是逐token递归状态更新打破了 Transformer 原本的序列级并行性；二是稠密 MoS 需要同时物化所有 $E$ 个专家的投影张量，导致激活显存随打包长度和专家数呈爆炸式增长。MemT-1.0 基于 Megatron-Core 与 Megatron Bridge 构建了专门的训练与推理基础设施。

针对串行更新瓶颈，系统引入了 **64 token分块 WY 更新与快照读取器分离（Chunked WY + Snapshot Reader）** 机制。利用 SGDN-2 更新的秩-1（Rank-1）代数结构，算子采用 **分块 WY 表示法（Chunked WY）** 将每 64 个连续token的串行向量-矩阵乘法聚合为下三角线性方程组求解与密集矩阵乘法（GEMM），在块间传递状态并在反向传播时重构中间量。更重要的是，MemT-1.0 将 **分块写入器（Writer）** 与 **快照读取器（Snapshot Reader）** 解耦：在第 $t$ 步的 2,048 个token内，所有查询统一并行读取步初的静态快照 $M_t$，而写入器在后台分 32 个微块（$32 \times 64 = 2048$）演进计算 $M_{t+1}$，从而兼顾了读取的高吞吐批处理与写入的时序精确性。

针对稠密 MoS 的显存膨胀问题，团队设计了 **完整步窗口化执行与重计算（Complete-Step Windowing）** 策略。在 32K token打包序列、4 专家 MoS 配置下，若一次性计算全包所有专家的投影（Whole-pack Execution），单个 MoS 记忆块的峰值激活显存高达 **47.83 GiB**。MemT-1.0 引入了以完整交互步（2,048 token）为单位的滑动窗口预算机制，每次仅物化 1 个或 2 个步长的专家投影，完成更新与读取后仅将 FP32 边界状态传递至下一窗口，并在反向传播时重计算窗口内部中间激活。

## 四、实验实验评估全景解析：记忆能力、抗噪表现与 agent-coding

### 4.1 11 项记忆基准测试与消融规律

研究团队在横跨四个轨迹长度区间（$<16\text{K}$、$16\text{--}32\text{K}$、$32\text{--}64\text{K}$、$>64\text{K}$）的 **11 个代表性记忆基准** 上，将 MemT-1.0 与两大家族方法进行了系统对比：一是 **参数化记忆基线（Parametric Memory）**，即推理时上下文不包含任何历史文本，完全依赖模型内部参数或状态（包括 Temp-LoRA、Doc-to-LoRA、SHINE、$\delta$-mem、LiveMem-RL、MemoryLLM、ICAE）；二是 **文本记忆基线（Textual Memory）**，即在推理时直接提供全量历史（Full Context，截断上限 256K）或通过外部检索系统注入文本片段（DenseRAG、MemOS、Mem0、OpenViking、Graphiti）。

实验数据首先确立了 MemT-1.0 在参数化记忆阵营中的统治力：MemT-1.0-Flash（50.6）和 MemT-1.0-Nano（47.0）在所有长度区间全面领先其余参数化记忆方案。

特别是在 $>64\text{K}$ 超长轨迹区间，传统参数化方法几乎全线失效（如 Temp-LoRA、$\delta$-mem、Doc-to-LoRA 在 LongMemEval-S 上仅得 13.4–14.8 分，在 MemoryAgentBench 上仅得 3.54–12.0 分），而 MemT-1.0 将 LongMemEval-S 提升至 **32.6–37.2 分**，将 BEAM-1M 提升至 **35.8–37.0 分**（接近 Full Context 受限于 256K 截断窗口取得的 43.7–44.7 分），并在综合均分上超越了基于时序知识图谱的外部记忆系统 Graphiti（49.4 vs 45.7）。

与此同时，第 6.7 节的在线奇异值分解（SVD）低秩压缩实验揭示了记忆状态内部的信息分布规律。研究团队在每次写入后对 Nano 的 $256 \times 256$ FP32 状态矩阵做在线 SVD 截断重构（保留秩 $k \in \{1, 2, \dots, 256\}$）。实验表明，PersonaMem 的准确率在中间秩（约 $k=16\text{--}32$）即迅速饱和并达到峰值，继续增加秩不再带来收益；而依赖细粒度多跳会话事实的 LoCoMo 则随秩 $k$ 增加持续上升直至满秩 $k=256$，但边际收益在 $k \ge 64$ 后显著递减。这证明用户画像等高层语义特征高度集中在状态矩阵的主奇异向量子空间内，而细粒度事实回忆则需要消耗长尾奇异值容量。

为了进一步检验当记忆槽中存有无关干扰记忆时是否会损害基座的推理、数学与编程能力，第 6.3 节在测评前向记忆中注入了无关领域的示范问答（如测评 MMLU-Pro 前写入 3 道 BigCodeBench 编程题，测评编程与长文本前写入 10 道 AIME 2026 数学竞赛题）。结果显示，**MemT-1.0-Flash 在 6 项通用基准上的平均分与同噪声设置下的 DeepSeek-V4-Flash 基座完全持平（差值为 0.0，均分 75.4）**，在 BigCodeBench-Hard（+2.0）和 IFEval（+0.9）上甚至略有反超；MemT-1.0-Nano 平均仅微降 **0.9 分**（主因是 LiveCodeBench v6 下降 5.8 分，但在 IFEval 上提升 +3.3 分、BigCodeBench-Hard 提升 +2.0 分），证明输出门控机制能够有效屏蔽无关记忆噪声。

### 4.2 Scaling Behavior：训练曝光度与 MoS 专家容量

第 5 章专门探究了原生记忆模型的两个专属缩放维度。在 **训练与数据曝光缩放（Data & Training Scaling）** 方面，固定 MemT-1.0-Nano 架构并在同一个 14B 后训练语料上连续训练 2 个 Epoch 时，前 0.25 个 Epoch 内平均分从 CPT 初始点的 **36.65 陡升至约 42 分以上**，第 1 个 Epoch 结束时达到 **45.40**（LoCoMo 从 40.39 升至 55.39）；进入第 2 个 Epoch 重复遍历相同数据时，性能并未过拟合饱和，最终检查点进一步攀升至 **46.80**（LoCoMo 达 **57.53**），说明即便在固定状态容量下，超记忆参数对读写策略的优化仍有可观余地。

在 **记忆容量缩放（Memory Capacity Scaling）** 方面，团队在 400 步 CPT 后对比了 MoS 挂载 **2 个记忆专家** 与 **4 个记忆专家** 的后训练表现。在训练初期（200 步），4 专家仅比 2 专家高出 0.41 分（40.06 vs 39.65）；但随着训练推进至 3,400 步和 5,500 步，4 专家的优势扩大至 **+2.01 分**（44.29 vs 42.28）和 **+2.69 分**（44.68 vs 41.99），LoCoMo 得分优势亦达到 **+3.25 分**（53.51 vs 50.26）与 **+2.20 分**（55.58 vs 53.38）。这证实了“更大容量的记忆状态需要充分的后训练步数才能被激活利用”的协同缩放规律。

### 4.3 Agentic Coding：基于原生记忆的程序性经验内化

报告第 7 章展示了 MemT-1.0 极具前瞻性的应用方向，即将原生记忆从“被动的信息复述（Factual Recall）”推向“主动的多步程序性策略引导（Procedural Guidance）”。在解决软件工程代码修复任务时，研究团队基于 Scale-SWE 发布的 41,057 条成功代码修复轨迹，通过轨迹标注、DeepSeek-V4-Pro 策略归纳（抽象为“当触发条件 X 出现时，执行步骤 Y，用 Z 验证，注意陷阱 W”）、聚类去重与质量审计，构建了一个包含 **1,040 条结构化编程经验（Experience Bank，平均渲染长度 456 token）** 的经验库。

为了训练模型通过原生记忆使用这些经验，团队采用 **反事实断点续写（Counterfactual Execution）** 管线生成了高质量监督信号：首先使用 Qwen3.6-35B-A3B 在 AweAgent 框架下生成 18,820 条原始轨迹，筛选出其中 **14,649 条失败轨迹（占 77.8%）**，并根据命令报错、空观察返回或连续重复无效操作（$\ge 3$ 次）提取了 19,950 个候选断点。在每个断点处，系统用 BGE-M3 检索相关经验并组合成 10 个候选子集注入，从同一状态恢复执行，共计评测了 **199,500 条断点干预分支**，并严格筛选出“原始轨迹失败、但注入经验后通过全部单元测试”的 **45,481 条成功续写分支（成功率 22.8%，质检后保留 42,403 条训练样本）**。训练时采用三阶段隔离子流：先将经验文本 $g_{b,j}$ 写入原生记忆状态 $M$，随后在关闭记忆读取的情况下回放断点前的失败前缀 $\xi_{\le b}$，到达断点 $b$ 后开启记忆读取，采用全后缀（Full-Suffix）Top-64 知识蒸馏损失，让仅靠读取记忆状态 $M$ 的学生模型逼近上下文中直接看得到经验文本 $g_{b,j}$ 的冻结基座教师。

## 五、Rethink

有些数字好看了很多，但也暴露出来很多问题。

### 5.1 理论证明与消融实验：SGDN-2 究竟贡献了多少实际性能？

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1792502561441_image.png)

报告在第 2.2 节与附录 C 中花费了大量篇幅推导标准 GDN-2 的非对称不稳定性（证明其最坏情况下半衰期仅 4.82 token），并将对称化修正 **SGDN-2** 树为核心理论支柱。然而，审视第 6.4.1 节表 4 的消融实验结果却会发现一个耐人寻味的反差：当把 MemT-1.0-Nano 的稳定化机制移除、直接退回标准 GDN-2（`w/ GDN-2`）时，11 个基准的平均分仅从 $47.0$ 微降至 **$46.4$（仅相差 $0.5$ 分）**；若直接替换为一代标准 GDN（`w/ GDN`），平均分为 **$46.7$（仅相差 $0.3$ 分）**，在 $<64\text{K}$ 的多个子项（如 PSB 98.3、PMS 40.9、MO 50.6）上甚至还略高于 SGDN-2。

为什么理论上会指数级发散的 `w/ GDN-2` 在实际评测中并未崩溃？原因在于附录 C 的证明基于“最坏情况谱范数上界（Worst-case Spectral Norm）”，要求每一步输入键都恰好处于最大正交放大角且遗忘门不起作用。在实际训练中，由于状态采用 FP32 高精度存储、键向量经过严格 L2 归一化，且端到端 KL 蒸馏会自动约束门控权重 $W_\beta$ 避开病态放大区间，标准 GDN-2 在常规长度下并不会频繁触发极端上界。表 4 的消融数据清晰表明，真正让 MemT-1.0 相比前代实现质的飞跃的，不是更新公式从 GDN 换成 SGDN-2（$+0.3\text{--}0.5$ 分），而是 **更新粒度从回合级（`w/ TL`，41.0 分）升级为逐token级（Token-level，+6.0 分）** 以及 **后训练阶段的离线策略 Top-64 KL 蒸馏（相比 `w/o PT` 暴涨 +10.7 分）**。当然，SGDN-2 在 $>64\text{K}$ 超长基准上依然展现出一致的领先（如 LME 上 32.6 vs 29.4，MAB 上 15.5 vs 14.4），它更多是作为长序列训练不溢出的“数学安全阀”，而非提升记忆召回率的决定性因素。



### 5.2 “固定容量 $O(1)$ 状态”的物理极限：参数化记忆与外部 RAG 的巨大鸿沟

尽管 MemT-1.0 以 50.6 分大幅刷新了参数化记忆的 SOTA，但将其置于表 2 中横向对比便会看到：**在长程精确信息检索任务上，固定容量的线性关联记忆矩阵与显式保留文本的外部记忆系统（如 MemOS 68.6 分、Mem0 66.0 分，乃至最朴素的 DenseRAG 57.3 分）之间仍存在着近 15 至 45 分的巨大鸿沟**。具体而言，在 $>64\text{K}$ 的 LongMemEval-S 和 BEAM-1M 上，MemT-1.0-Flash 仅取得 **37.2** 和 **37.0** 分，而基于同基座的 MemOS 高达 **83.2** 和 **72.6** 分，甚至最简单的 Top-10 DenseRAG 在 LongMemEval-S 上也能拿到 **69.4** 分。

这一差距源自线性关联记忆体的物理容量极限。MemT-1.0 的局部记忆状态 $M_t \in \mathbb{R}^{H_{kv} \times d_k \times d_v}$ 本质上是一个基于外积叠加的快速权重矩阵（Fast Weights）。当历史长度 $N$ 远大于键维度 $d_k$（例如将 10 万个token压缩进 $d_k=256$ 或 $512$ 的正交基空间）时，不同历史时刻的键向量不可避免地发生非正交重叠（Superposition Interference）。后续的擦除门 $\beta$ 在擦除旧状态以写入新信息时，必然会连带冲刷掉共享同一子空间的早期细粒度事实（如具体数字、日期或专有名词）。这也解释了为何 MemT-1.0 在偏好理解、隐式适应（ImplicitMemBench）、安全感知（PS-Bench 97.5）和程序性规则应用上表现优异，但在大海捞针式的精确长程事实召回上无法替代外部 RAG。



### 5.3 混合存储（MoS）的“缺席”悖论：旗舰开源权重为何仅用单专家（$E=1$）？

报告将 **混合存储（MoS）** 作为三大核心架构贡献之一，在第 2.3 节、第 4.2 节（窗口算子）和第 5.4 节（容量缩放）进行了重点阐述。然而，仔细查阅附录 B 表 6 的模型配置表却会发现一个关键事实：**在主实验（第 6 章）中评测并发布的两个核心模型 `MemT-1.0-Nano` 和 `MemT-1.0-Flash`，其每层记忆专家数均为 `Memory experts per layer = 1`，即在最终发布的旗舰权重中并未启用 MoS 多专家扩展**。

结合第 4.2 节与第 2.3 节可以推断出背后的工程代价掣肘：由于 MoS 采用了 **全专家稠密路由（Dense Routing）** 而非稀疏激活，当专家数扩充为 $E=4$ 时，每一层超记忆块的可训练参数量、读写投影计算量（FLOPs）以及单会话持久化状态体积都会直接膨胀 **4 倍**（例如 Nano 的状态将从 40 MiB 增至 160 MiB，Flash 则将从 1.28 GiB 暴涨至 5.12 GiB），且训练时必须依赖窗口化重计算来压制高达 47.83 GiB 的激活峰值。如何在未来将 MoS 改造为真正的 **稀疏激活路由（Sparse MoS）**——即每次仅更新和读取 Top-$k$ 个相关记忆槽，从而打破容量与算力耦合——将是下一代架构亟待攻克的课题。



### 5.4 MemT-1.0-Flash 与 Nano 的边际收益递减与局部倒挂

对比两个量级的模型配置（附录 B 表 6 与正文表 2），`MemT-1.0-Flash` 的底层基座总参数是 `Nano` 的 **8 倍**（288B vs 36B），激活参数是 **5.7 倍**（17B vs 3B），可训练超记忆参数是 **8 倍**（3.61B vs 0.45B），单轨迹 FP32 记忆状态体积更是高达 **32 倍**（1,280 MiB vs 40 MiB）。然而，付出如此庞大的算力与存储代价后，Flash 在 11 个记忆基准上的总平均分仅比 Nano 高出 **3.6 分**（50.6 vs 47.0），在 $>64\text{K}$ 的 BEAM-1M 上仅高出 **1.2 分**（37.0 vs 35.8）。更令人意外的是，在 32–64K 区间的 **PerMemSafe**（38.7 vs 33.5，Nano 领先 **5.2 分**）和 **Memora**（23.9 vs 20.5，Nano 领先 **3.4 分**）上，小巧的 Nano 反而击败了庞大的 Flash。

这一现象揭示了两个深层问题。其一，Flash 将记忆块挂载在 DeepSeek-V4 的 **压缩稀疏注意力层（Compressed Sparse Attention）** 上，其键值投影采用了复杂的 8 组 512 维瓶颈分组重构（将局部 KV 投影 $L$ 与压缩注意力前后半区 $P, C$ 按 8 种排列组合拼接初始化，见附录 B.1），这种跨异构特征空间的强行配对可能不如 Nano 在 Qwen3.6 标准全注意力层上的直接复制初始化自然平滑。其二，面对 3.35 亿状态元素与 36 亿超记忆参数，相同的 34B 训练token对 Flash 而言可能处于 **欠训练（Under-trained）** 状态，导致庞大的记忆矩阵未能被充分优化利用。



### 5.5 智能体经验内化的本质：方差抑制器而非探索放大器

在第 7 章 SWE-bench 智能体编程实验中，对比表 5 的三项指标可以洞察到一个关键规律：无论是 Verified 还是 Multilingual，注入原生记忆经验都使代表三次运行全部成功的 $\text{pass}^3$ 暴涨了 **7.6 至 10.0 个百分点**，但代表三次运行至少成功一次的 **$\text{pass}@3$ 却几乎没有提升，甚至在部分设置下微降**（例如 Multilingual 执行前写入模式下，无经验基座 $\text{pass}@3$ 为 73.67%，而文本经验和原生记忆分别为 72.67% 和 72.00%）。这说明内化到记忆中的程序性经验实质上扮演了 **“行为正则化与方差抑制器（Variance Reducer）”** 的角色——它通过提醒智能体遵循“先写复现测试、检查边界条件”等标准操作规程，大幅减少了原本会偶发失误的轨迹，但并不能赋予模型解决原本完全超出其能力边界的难题的探索上限（这与第 3.1 节关于基座准备只提升可靠性而不凭空创造能力的结论形成了呼应）。

同时，当前的智能体经验框架并非真正的“自主在线终身学习”，它依然依赖外部构建的静态经验库（由更强的 DeepSeek-V4-Pro 离线提炼）以及外部向量检索模型 BGE-M3 来挑选经验（且附录 E.1.1 指出问题级检索区分度有限，Top-1 与 Top-5 余弦相似度中位差距仅 $0.029$）。此外，为了让模型学会读取该经验库，团队不得不先运行近 **20 万次** 代码沙盒执行来筛选反事实轨迹并专门进行一轮领域微调，距离全自动的环境交互自演化仍有不小的工程距离。



## 六、总结

**MemT-1.0** 这次通过严谨的数学对称化修正（**SGDN-2**）解决了多通道解耦线性注意力在递归擦除中的正交能量放大缺陷，虽然感觉从消融实验来看，提升有限，甚至还有负提升，不知道后续有没有进一步改进。

然后训练流程和infra也做了很多工作，以 **逐token细粒度更新** 与 **34B 规模的“CPT + 离线策略全上下文 KL 蒸馏”** 激活了多通道记忆矩阵的表达潜力，并借助 **64 token分块 WY 算子**、**快照读写解耦** 与 **窗口化重计算** 构建了工业级的高效训练与 $O(1)$ 有状态推理底座。

感觉以后如果要做原生记忆，可以考虑在端侧场景，做那种 **混合原生-外部记忆协同架构（Hybrid Native-External Memory）**：

鉴于固定大小 $O(1)$ 矩阵在长程细粒度事实回忆上的物理压缩瓶颈（如 LongMemEval-S 上 37.2 vs 83.2 的差距），未来的理想形态不应是用原生记忆完全取代外部 RAG，而是实现分工协同——将高频使用的用户画像、隐式交互风格、推理规范与程序性技能（Skills/Experiences）沉淀于模型侧 **原生记忆状态 $M_t$** 中实现零上下文开销的直觉引导，同时将低频、高精度的海量冷事实交由外部符号或向量库按需调取。



然后这个 MoS 做的有点粗糙，其实可以做成 **稀疏激活混合存储（Sparse MoS）与非线性记忆读取**，通过将当前全专家参与计算的稠密 MoS 升级为基于语义地址路由的 Top-$k$ 稀疏读写架构，在不增加单步算力与激活显存的前提下将单轨迹记忆容量推向 GB 级，缓解线性外积叠加带来的子空间串扰。



还有就是如何 **从局部记忆（Local Memory）向超记忆（Hyper Memory）的睡眠固化闭环**，正如报告第 8 章所探讨的，若能设计一种类似生物大脑“海马体向新皮层记忆巩固（Memory Consolidation）”的机制，将局部记忆状态 $M_t$ 中高频验证有效的多步经验周期性地蒸馏内化进超记忆参数 $\phi$ 乃至基座权重 $\theta_b$ 中，大模型才真正具备跨任务、跨生命周期的原生自我演化能力。
