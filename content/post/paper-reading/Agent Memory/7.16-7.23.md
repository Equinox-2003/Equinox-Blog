## 一、关于 memory cost

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1784821204803_image.png)

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1784826177737_image.png)

>   来源：ICML 2026
>
>   [调研：BudgetMem](https://equinox.wiki/post/paper-reading/agent-memory/budgetmem%E7%B2%BE%E8%AF%BB/)

这个关注的成本就是：**runtime memory extraction cost：为了从历史中提取本次回答所需记忆，要调用多少模型、消耗多少 input/output token、支付多少钱。**

然后针对这些问题呢，他用PPO 分别训练了仨 router：

-   BudgetMem-IMP：路由检索的规则
-   BudgetMem-REA：路由推理强度
-   BudgetMem-CAP：路由model的size

然后实验里面三个router策略基本都是在 cost 降低的情况下，benchmark 还能高于一众baseline。

然后他这仨router不是联合工作的，是单独训练，单独使用的。所以自然而然的就有怎样做混合策略的router的后续方向罢（。

还有一个点就是，他这个工作不同于之前的各种memory manager，那些都是离线的，他这个是在线的。因为离线就要提前做summary，会丢失细节，他这里存的是原始对话的片段，查询来了才做相应总结。



## 二、关于多模态memory

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1784630852636_image.png)

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1784718708135_image.png)

>   来源：CVPR 2026
>
>   [调研：ViLoMem](https://equinox.wiki/post/paper-reading/agent-memory/vilomem%E7%B2%BE%E8%AF%BB/)

他这个想法就是：多模态推理失败并不只有“数学公式没想对”。很多逻辑错误的上游原因，是模型一开始就**看错了图**，例如漏掉符号、混淆材质、误读空间位置，随后再用很流畅的语言把错误推理到底。

然后做法也很工程化：

1. 对新图文题，从视觉库和逻辑库并行检索经验；

2. Solver（解题模型）在这些经验帮助下作答；

3. Verifier（验证器）拿**答案与标准答案**比较；

    >   他这个工作面向的是离线带标签环境，其实就是在一个离线题库里面锻炼多模态解题经验

4. 若答错，由模型分别判断是否存在视觉错误、逻辑错误；

5. 把新规则与相似旧规则合并，或新增一条，供以后使用。

也就是分别维护了文本逻辑 和 <图片，视觉逻辑>，对于问题做并行检索，感觉很无聊。

现在关于多模态 memory 的文章疑似都同质化严重，所以后续应该暂时不会再看这方面的了。



## 三、参数化memory

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1784535791437_image.png)

![image.png](https://8504cc9c.cloudflare-imgbed-8qo.pages.dev/file/1784550923073_image.png)

>   来源：ICLR 2026
>
>   [调研：MLP Memory](https://equinox.wiki/post/paper-reading/agent-memory/mlp-memory%E7%B2%BE%E8%AF%BB/)

这个其实也是考虑到 memory 检索的成本问题了。

他觉得rag 的问题就是检索时延、噪声，然后之前的 knn-LM效果很好，但要找最近邻又太慢了。

所以他就想，LoRA那种很快呀，只不过LoRA本身会有遗忘、新知识不好学之类的。所以就训练一个 MLP 去学习 knn 的检索能力。

MLP 的输入是 transformer 某层的hidden state，然后输出就是概率，作用于llm内部概率加权。

然后这样效果提上来了，效率也高。

不过这种外置 adapter 都得专门训练，不是可插拔的就是了。
